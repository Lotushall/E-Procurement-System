# ประกาศ TOR ก่อนเปิดรับซองได้

เมื่อ 2026-10-31 ตัดสินว่าเจ้าหน้าที่กำหนดวันเริ่มรับซองให้หลังวันประกาศได้ ผู้ค้าจะได้อ่านและเตรียมข้อเสนอล่วงหน้า จึงเพิ่มขั้น `published` (ประกาศแล้ว) ระหว่าง `approved` กับ `bidding` ถ้าไม่กำหนดวันเริ่ม TOR จะเข้า `bidding` ทันทีที่ประกาศเหมือนเดิม ทางเลือกที่ไม่เลือกคือการตั้งเวลาประกาศอัตโนมัติ (TOR อยู่ `approved` และผู้ค้ายังไม่เห็นจนถึงวันเริ่ม) เพราะผู้ค้าจะไม่มีเวลาเตรียมตัวก่อนช่วงรับซอง

## Consequences

- `bidding_start_at` คือวันเริ่มรับซองที่กำหนดไว้ ไม่ใช่วันประกาศ วันประกาศจริงเป็นเหตุการณ์ในไทม์ไลน์
- การแก้ TOR ในขั้น `published` เป็นการแก้ไขสำคัญ เพราะผู้ค้าเห็น TOR แล้ว
- ช่วงรับซองกำหนดตั้งแต่ร่างและอนุมัติไปพร้อมเนื้อหา ประกาศไม่ได้ถ้าวันในช่วงนั้นผ่านไปแล้ว และการแก้ใดๆ หลังอนุมัติแต่ก่อนประกาศจะทำให้ TOR กลับไป `in_review`
